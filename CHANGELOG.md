# Changelog

## 0.1.0 — 2026-10-27

First version: create and run several Dragonwilds dedicated servers from a web panel on Windows, Linux or Docker. SteamCMD install/update, process supervision with crash restart and clean shutdown, live console, players with kick/ban/whitelist and play time, settings, world settings, worlds (import/switch), pak mods, backups (make/restore/upload), cron schedules, English/Dutch.
