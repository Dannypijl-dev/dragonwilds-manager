# Changelog

## 0.1.2 — 2026-10-27

New look for the panel: stone frames with cut corners and the title on the edge, a rune-stone mark, Grenze and Alegreya Sans (loaded from Google Fonts, with system fonts as fallback), an ash palette with verdigris for online and dragonfire for busy states, the server list as full-width rows, and the server page opening with the name and state as a header. Same Flask templates and CSS, no new dependencies.

## 0.1.1 — 2026-10-27

First published release (0.1.0 was tagged but its Docker image build failed on the image name).

## 0.1.0 — 2026-10-27

First version: create and run several Dragonwilds dedicated servers from a web panel on Windows, Linux or Docker. SteamCMD install/update, process supervision with crash restart and clean shutdown, live console, players with kick/ban/whitelist and play time, settings, world settings, worlds (import/switch), pak mods, backups (make/restore/upload), cron schedules, English/Dutch.
